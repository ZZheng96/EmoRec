# 实验217：相似度分组与 DEP 专用微调/多核冲刺计划

## Context

公开测试当前最佳为 81.88，排行第一方案明确采用“脑电相似度分组、健康组通用融合、抑郁组微调网络与专用多核 SVM”。已有实验208只验证了低性能的通用软路由，实验211只验证了按 HC/DEP 标签硬切换，不能代表排行第一方案。实验217用于在不读取公开标签的前提下，直接复现其核心结构，冲击公开 AUC 92；92 不能由本地 OOF 保证，最终以平台公开成绩为准。

## 实施范围

新建独立目录：

`test/experiments/217_subject_similarity_expert/`

新增：

- `config.json`：预声明随机种子、聚类数、路由温度、微调轮数/学习率、多核 SVM 参数和固定融合权重。
- `run_experiment.py`：严格 subject-wise 5-fold OOF；折内拟合标准化、相似度原型和路由；训练 HC 通用融合分支、DEP 相似组专用微调分支、DEP 多核 SVM 分支；输出窗口/物理 trial/HC/DEP AUC 和固定阈值 F1。
- `run_public.py`：全训练集重训并对公开集无标签推理，输出80行提交文件和完整审计。

## 推荐实现

1. 复用实验216的 `trial_features` 作为通用统计输入，叠加057 `plus_pe`、频谱/DE特征和STFT残差作为通用融合分支。
2. 复用实验208的无标签被试描述、KMeans原型和softmax距离路由，但只使用训练折拟合原型；不使用验证标签选择分组、温度或权重。
3. 在训练折内建立相似度组：相似度描述使用每被试无标签频谱、DE、PE和STFT统计；DEP专用分支只在与目标DEP原型相近的训练被试/样本上训练，采用专用多特征 SVM 分数融合。
4. DEP深度分支使用现有 `src/emo_rec/finetuning.py` 的 `make_optimizer`、`seed_training`、`train_epoch`、`predict_logits`；先冻结或低学习率更新 backbone，再用较高学习率更新分类头。
5. 公开推理时只依据公开被试自身无标签描述计算路由，HC通用分支与DEP分支做软融合；不按“最高4个”硬改标签，不读取公开标签。
6. 固定融合采用训练协议事前声明的权重；不得根据公开提交分数反向修改同一候选的权重。

## 严格约束

- 每个被试只能出现在一个验证折；同一物理 trial 的窗口不能跨折。
- 所有 scaler、KMeans、SVM、微调模型和路由统计均只用外层训练折拟合。
- 公开集标签不读取；公开 AUC/F1 在报告中记为未知，不能伪造。
- 使用 CUDA；长任务输出 fold、模型分支、epoch、loss 和进度。
- 实验报告必须记录窗口 AUC/F1、HC/DEP AUC/F1、trial AUC/F1、最差折、概率范围和审计哈希。

## 验证与停止条件
