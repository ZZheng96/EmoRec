# 实验087：训练折内类别条件原型残差

## 协议

严格比较070固定720维a8 HGB基线与训练折内类别条件原型残差。控制臂直接复用070的a8训练→a8验证OOF；处理臂每个外层训练折先训练raw a8 HGB，以训练真实标签拟合0/1类原型，训练侧使用真实标签、验证侧使用首轮raw HGB的0.5伪标签选择类原型。仅加入所选类原型的逐维绝对残差均值1个标量，因此处理输入为720+1维；再以070固定HGB重训。HC43排除，fixed002及2042..2046五重复被试级5折，共30个外层fold作业、60次真实模型fit（首阶段raw HGB 30次，第二阶段处理HGB 30次）。运行时沿用086的NPZ训练键白名单、public路径及公开loader拦截，包住实际load_data，不访问公开数组。

## 接受判断

预注册目标为平均delta AUC和F1至少+0.005、各自至少4/5重复非负、HC/DEP平均delta AUC不低于-0.005。本实验 **未通过**：`metrics.json.acceptance.accepted=false`。六项检查中仅DEP无过度下降通过；平均AUC、平均F1、非负重复数及HC约束均未通过。结果表明该严格训练折内原型残差摘要相对070基线下降，不能宣称提升。

## 复核与产物

2026-11-02保持预测算法和超参不变重跑，耗时421.95秒。前测3 passed、1 deselected（排除旧产物校验），重跑后4 passed（12.04秒）。后测直接使用sklearn从六份OOF复算AUC/F1，核对五重复均值、样本SD及逐重复delta，全部一致。训练数据为69人2760行。

`metrics.json` 保存60次分阶段实际fit耗时、30折首阶段预测对070的误差及guard运行证据。六组控制在训练前逐行核对row_index、subject、group、trial、y、position、fold；首阶段独立重训概率在全部30折与070匹配（容差1e-12），不是把拷贝控制与自身相减。`predictions/*.csv`另存p_first_stage以便复核。`input_metadata/provenance.json`补齐实际读取的三个缓存、fixed reference、070历史递归依赖及src源码hash；guard记录实际加载路径及训练键，未加载原始mat或公开数组。所有记录hash经后测验证。

HGB无GPU实现，按冻结模型协议使用CPU、n_jobs=10、线程上限1。原型由外层训练数据拟合，验证真实标签未参与任何变换或伪标签选择。但训练侧使用真实标签选择残差、验证侧使用预测伪标签，明确存在train/inference构造失配；这不是外层验证标签泄漏。该实验只是标签选择原型距离的启发式追加特征，没有显式条件分布对齐目标，不能称为条件分布对齐。失败仅否定当前启发式配置，不能否定全部条件域适配。五个重复不是独立外部队列，亦不代表公开测试性能。
