# 实验047：逐窗口 STFT 时频图 + 轻量 CNN 对比频谱 HGB

本实验严格按10秒窗口、30通道STFT构造 `30×F×T` 时频张量，固定 `nperseg=128、noverlap=64、nfft=128`，保留1–45Hz（23个频率bin），不使用标签、original_trial_id、行序、邻窗或公开标签。HC43排除；固定折复用002，另运行2027..2031五个独立被试分层重复。CNN每个外层折重新初始化，训练折拟合通道尺度，验证/公开只transform；HGB在同一脚本逐折重训作为控制。阈值固定0.5，公开仅保存预测。

## 结果

运行后由脚本写入 `summary.csv` 与 `metrics.json`，其中包含固定折/每个重复的AUC、F1、BAcc、subject宏AUC、HC AUC、DEP AUC，以及每折/每被试明细和训练审计。

## 结论规则

若固定折或重复结果未超过频谱HGB，按协议停止，不调参追分；若重复成本过高，必须在此记录未完成状态，不伪造结果。
