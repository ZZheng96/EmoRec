# 实验124冻结协议

- 输入仅为 DEP02 原始训练 MAT；40个窗口按文件顺序切分，物理trial每5窗，保留窗口顺序。
- 每窗计算五频带log-bandpower（30通道）及固定左右镜像不对称（5×30=150）。
- 每trial逐基础维度计算 mean、std、t=-2..2线性slope、last-first、mean(first2)-mean(last2)。候选形态为mean或五类动态量全量。
- 特征块为power、asymmetry、all。每训练折严格StandardScaler→PCA(1/2/3)→LogisticRegression(C=.1/1/10)。
- 54模型候选及raw/reverse共108项；inner仅训练trial OOF选择，outer验证标签禁用。
- outer为4×4正负物理trial pairs，inner为3×3；报告pooled quota4、fixed0.5与pair均值。
- 单线程CPU；源文件、配置、协议、数据说明哈希写入provenance。
