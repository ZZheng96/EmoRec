# 实验023：多分辨率短时频谱 HGB

本实验从原始EEG每个10秒段切分5个2秒子窗，逐窗调用现有 `extract_spectral_features`，仅保留150维log-bandpower并拼接为750维。控制组复用001频谱和009时序缓存；先核验全部元数据逐行一致，再排除HC43并复用002固定5折。所有条件均采用按被试无标签zscore、StandardScaler及实验016/017固定HGB参数，不调参、不使用验证标签。

每组输出2760行OOF和80行公开集预测；每折指标详见metrics.json。局限：固定折复用可能带来模型选择偏差；公开集无标签，不能计算泛化指标；仅比较单一固定HGB协议。
