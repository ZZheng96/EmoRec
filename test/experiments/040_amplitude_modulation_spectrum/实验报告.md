# 实验040：逐10秒EEG频带包络调制谱

本实验从原始EEG逐独立10秒窗口计算。每通道以四阶零相位Butterworth带通提取1–4、4–8、8–13、13–30、30–45 Hz，Hilbert幅度包络平方后以Welch功率谱在0.2–0.5、0.5–1、1–2 Hz积分并log1p，得到30×5×3=450维；控制为同一窗口原始EEG五频带log功率150维。滤波使用sosfiltfilt默认边界填充，窗口间不拼接；250 Hz、2500采样点。训练与公开完全同一算法，每被试/公开user独立无标签z-score。

排除HC43后使用69名被试2760训练窗口和80公开窗口；固定复用002五折，HGB沿用039/016参数，阈值0.5。固定融合是每折分别重训后的0.5/0.5概率融合；重复seed=2032、2033、2034仅分别保存control和modulation结果，不拼接OOF、不做显著性检验。
