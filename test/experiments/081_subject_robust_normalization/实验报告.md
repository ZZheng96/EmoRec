# 实验081：被试内、位置内 robust median/MAD 归一化

## 唯一假设与冻结方法
仅检验robust median/MAD是否优于070均值/std z-score。控制直接复用070保存p_train8；处理为p_robust8；两者均a8训练、a8验证。150 spectral + 450 temporal + 120 PE共720维完全不变。
每个subject每个position恰8窗，逐特征中心为median，scale=1.4826*median(abs(x-median))；scale<=1e-12时用1.0。归一化不读取标签，不跨被试或位置，无调参、挑位置、公开测试数组读取。
依据数据集说明：训练70人、30通道、250Hz；排除HC43后69人2760个10秒窗。fixed002及repeat2042..2046六套subject-level 5-fold，HGB、seed、阈值完全冻结。仅处理30 fits，不重训控制，不计算40窗上下文。
