# 实验091：单被试个体情绪判别严格实验

## 研究动机与冻结协议

本实验针对个体内情绪判别，避免跨trial窗口泄漏。排除HC43后使用69名被试、每人40窗、8个物理trial（`(y, original_trial_id)`，每trial 5窗），输入为现有训练缓存拼接的720维特征（150 spectral + 450 temporal + 120 PE）。每个被试先用全部40窗做无标签逐特征zscore（ddof=0）。外层采用8折 Leave-One-Physical-Trial-Out：每折训练35窗、验证完整5窗；每个被试独立产生OOF。

外层训练集内使用7个trial的Leave-One-Trial-Out inner CV，在固定候选 HGB、LogisticRegression、LinearSVC 中按 pooled inner AUC选择，AUC平局按F1再按固定候选顺序裁决；外层验证标签未参与方法选择。LinearSVC使用decision function 的 sigmoid 概率变换。未访问公开数组。

## 真实结果

- 整体 pooled AUC：**0.6768173703**
- 整体 pooled F1：**0.6225736880**

- 宏 subject F1：**0.6200124413**
- 方法选择总次数（69×8=552折）：HGB **2**，LogisticRegression **5**，LinearSVC **545**。

| HC45 | HC | 0.360000 | 0.312500 | 0 | 0 | 8 |## 困难与局限

- 单被试每个外层训练集仅35窗，且inner每次训练30窗，LinearSVC在小样本高维条件下占据绝大多数选择；这反映协议约束下的模型偏好，不代表其跨被试或公开测试集最优。
- 每个被试只有8个物理trial，OOF评估方差较大；宏平均和pooled结果回答不同问题，不能互相替代。
- 全40窗无标签归一化允许使用验证窗的无标签分布，属于冻结的transductive个体内协议；没有使用验证标签。
- 论文仅用于研究动机和方法语境，不能借用论文成绩或宣称本实验复现其结果。
