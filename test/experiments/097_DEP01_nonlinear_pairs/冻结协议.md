# 097 DEP01 非线性配对协议（运行前冻结）

唯一假设：096 的线性模型可能无法刻画非线性。仅替换为 RBF SVC，不转移其他被试。

- 复用096的原始特征加载、trial键、特征块和outer均值聚合；DEP01共8 trial，每类4 trial，每trial 5个窗口，共40窗口。其他被试仅随历史缓存加载，不参与拟合或选择。
- outer 4×4正负trial配对共16次：训练30窗口、验证10窗口；inner在剩余3×3 trial中共9次，训练20窗口、验证10窗口。整个trial隔离。
- 固定32候选顺序：block=[all,spectral,temporal,PE]，再C=[0.1,1,10,100]，再gamma=[scale,0.01]；kernel=rbf，其余采用当前sklearn默认参数。无概率校准。
- 每次inner/outer拟合均仅训练数据拟合StandardScaler。decision_function截断到[-60,60]后原向sigmoid，固定阈值>=0.5；不反转、不调阈值。
- inner每窗口3个预测取算术均值，依据30窗口pooled AUC、F1、固定候选先后次序选择。选择函数仅接收outer训练特征、标签与trial键；outer标签不传给选择函数。
- outer每窗口4个预测均值形成40行OOF，明确prediction_count=4，无无意义fold列；保留160行pair长预测。报告pooled与16 pair指标算术均值，以及常数0.5先验对照（>=0.5均判正类）。
- 保存全部inner候选分数与均值预测、内外train/valid局部索引（对应OOF行序）、依赖源码/输入SHA256和版本。
- 先测试、再运行、再测试；运行后复算指标及聚合。小样本sklearn/libsvm CPU求解，单线程避免调度开销，现有依赖无GPU SVC实现。
- 096 AUC=0.16，F1=0.157895，属于开发参考。反复使用同一8 trial选择研究方向，存在跨实验适应性开发偏差；即使嵌套分组没有直接泄漏，本结果也不是独立确认，不能作为独立泛化证据。禁止依据outer表现重新选择候选或方向。
