# 实验043：训练折内监督滤波器组CSP + LR

训练与公开EEG均先切独立10秒窗，再逐窗4阶Butterworth SOS零相位五频带滤波。缓存仅含无标签逐窗协方差；各折仅训练被试标签拟合CSP（类均值迹归一化协方差，广义特征分解，两端各2，共20维），投影原始窗口协方差取log variance。StandardScaler+LR仅训练折拟合，无邻窗、行序或trial id输入。HC43完全排除。固定折在全部70被试生成后排除HC43，与002一致；重复2027..2031在69被试生成，与032一致。对照001前150维subject z-score + HGB每折独立重训，无读取历史OOF。对照subject z-score为无标签被试内转导统计，CSP不作subject normalization。阈值固定0.5，无调参。
