# 实验025：严格嵌套HGB与LaBraM辅助融合

旧版本协议已否定：016/004缓存OOF模型可能包含当前外层验证被试，旧结果不纳入结果。新协议从001与004特征缓存读取并严格核验subject_ids、y、trial、fold及公开键；每个外层fold内按被试3折，仅以内层训练被试重新拟合HGB和LaBraM LogisticRegression，生成真正内层OOF选择0.0至1.0、步长0.05的权重，再在完整外层训练集重训并预测外层验证。raw、subject_zscore及均值条件均不使用旧OOF概率；public模型用全训练集拟合且未读取public标签。

真实新结果见metrics.json、summary.csv和predictions；其中metrics记录每个内层/外层模型拟合次数、训练/验证被试集合及元数据核验。
