# 实验066：单窗非线性复杂度增量（v2）

## 数据协议澄清（2026-11-02）

依据《数据/数据集说明文档.md》：完整训练集为45名HC与25名DEP，每人8段视频（4中性、4积极），每段保留50秒；40个10秒窗是每视频5窗，不是40个独立视频。过滤HC43后为44名HC与25名DEP。分类目标为中性/积极，HC/DEP仅为被试分组。`original_trial_id`在两类内各取1..4，物理视频须联合被试、标签与该编号确定。

公开测试为5名HC与5名DEP，每人8段视频各保留10秒，顺序已打乱，标签不公开；不能从行序恢复标签，也不能把8窗当作统计独立样本。说明未提供训练测试视频身份及截取时间的对应关系。

本实验“单窗”仅指特征提取；OOF验证被试仍用自身全部40窗估计无标签z-score。实际公开用户只有8窗，归一化上下文并不匹配。当前OOF成绩仍是该40窗协议的结果，不是对8窗适应或公开性能的验证。尚需保持训练折不变、对留出被试每视频选1窗并仅用这8窗归一化的配对诊断；不能用本轮数值推断这种协议的结果。


本次v2仅生成训练集OOF；不提取公开集特征、不训练公开预测。目录内旧v1 public prediction 保留且未覆盖；旧v1结果可由git 9729e500追溯，但其数值不代表正确LZ76。
