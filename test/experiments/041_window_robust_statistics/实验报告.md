# 实验041：逐10秒窗口稳健时域/频带统计

从原始EEG逐个独立10秒窗口（250 Hz，2500点）以四阶Butterworth SOS带通和sosfiltfilt默认独立窗口边界提取1–4、4–8、8–13、13–30、30–45 Hz。每通道/频带计算median(abs(filtered))与IQR(filtered)，按频带、统计量、通道形成300维；spectral_control严格复用001缓存前150维150维频谱特征。训练与公开同构，每user独立无标签z-score。

排除HC43后2760行/69被试，公开80行；固定复用002五折，HGB参数与阈值0.5。融合每折重训后0.5/0.5。重复seed=2027..2031分别保存，不拼接OOF、不做独立显著性检验。公开集无标签，仅保存预测。
