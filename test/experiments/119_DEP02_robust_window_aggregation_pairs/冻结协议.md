# 实验119冻结协议：DEP02稳健窗口聚合严格配对

- 本协议于完整实验运行前冻结；仅修改119目录及进度，不覆盖旧实验，不读取旧预测或选择。
- 读取115使用的spectral/temporal/PE缓存，核验三份缓存元数据一致。实际DEP02 original_trial_ids在两类中各为1–4，单独只有4个唯一值；沿用115的`y::original_trial_id`物理trial键，得到8个trial、40窗口，每trial连续5窗。标签只用于恢复训练数据的物理trial身份，不作为模型输入。
- 特征块为all=720、spectral=150、temporal=450、PE=120。五窗逐特征聚合候选为mean、median、trimmed_mean；后者逐列排序，去掉最小及最大各一窗，平均中间三窗。聚合方法仅由outer训练集中的inner OOF选择。
- outer固定4×4正负trial pairs，每折6 train/2 valid；inner仅限outer训练集，3×3配对，每折4 train/2 valid。inner/outer共用排序后的valid索引，与flatnonzero提取的原始窗口顺序一致；训练索引同样升序。
- 模型为LR/LinearSVC/RBF-SVC；C=(0.01,0.1,1,10,100)；RBF gamma=(scale,0.01)。每聚合方法含2×4×5 + 4×5×2=80个候选，三种共240个模型候选，乘raw/reverse两方向共480项评分；方向不额外拟合模型。全实验预计16×(240×9+1)=34576次fit。
- 每次StandardScaler仅在该训练折聚合后的trial特征拟合。inner每trial概率平均后按AUC→F1@0.5→candidate index→direction index选择；select仅接收outer train特征、标签及局部trial ids。outer验证标签不参与模型、聚合、方向或阈值选择。
- decision_function经sigmoid转为有界评分（不宣称校准概率）；outer每trial覆盖4次后平均。主AUC使用pooled trial评分；主F1使用运行前冻结的top-4 quota，评分相同时按trial顺序稳定排序。另报告固定阈值>=0.5的AUC/F1及16个pair的AUC/F1与均值；pair F1也固定0.5，不使用pair quota。
- 达标字段由主pooled AUC>=0.95且quota F1>=0.95实际计算，不硬编码。失败也不更改协议重选。
- 仅8个开发trial；配对和重复OOF不是独立样本，多轮开发仍有选择偏差，不代表独立测试或跨被试泛化。quota依赖每被试完整8段中4中性/4积极的已知类数，不适用于未知比例或单trial独立推断。
- 使用现有sklearn CPU单线程小样本求解器；不为8个trial引入GPU替代实现。保存预测、选择记录、源文件与缓存SHA256、特征维度、trial窗口行号及运行时间。
