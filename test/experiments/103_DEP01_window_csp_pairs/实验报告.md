# 实验103：窗口级训练 FilterBank CSP + trial级概率聚合

| 指标口径 | AUC | F1 |
|---|---:|---:|
| 8个trial聚合OOF | **1.000000** | **0.666667** |
| Pair指标均值 | **0.937500** | **0.687500** |
| 常数0.5 baseline | 0.500000 | 0.666667 |

- outer每折训练30窗口、验证10窗口；inner每折训练20窗口、验证10窗口。
- CSP、StandardScaler、分类器只在训练窗口拟合；outer验证标签未用于选择。
- 运行耗时85.14秒，候选120个；每个trial由4次pair预测覆盖。
- AUC达到0.95但F1未达到0.95，因此DEP01仍未达标，不能进入DEP02。窗口级训练相对实验101（0.875000/0.857143）提高AUC但降低F1；该结果仅有8个物理trial，不能视为独立确认。
