# 实验090：subject-position集合logit中心化

## 结果

严格复用070的HGB配置、a8特征、fold协议和模型随机种子；每个fold仅fit一次。控制为同一fold模型的原始 `p_control`，处理为每个 subject-position 的8个验证窗在不使用标签下进行 logit 均值中心化后的 `p_calibrated`。固定002控制逐行复现070的 `p_train8`，最大绝对误差见 `metrics.json`。

| 指标（五个repeat all_rows均值） | control | calibrated | calibrated-control |
|---|---:|---:|---:|
| AUC | 0.811834 | 0.814419 | +0.002585 |
| F1 | 0.734998 | 0.735268 | +0.000270 |
| HC AUC | 0.861901 | 0.864892 | +0.002991 |
| DEP AUC | 0.706898 | 0.709328 | +0.002430 |

接受线结果：未达到预注册线（平均ΔAUC/ΔF1均需至少0.005；AUC五个repeat均非负，F1为2/5非负）。实验本身按冻结协议完成，不据此宣称公开提升。
