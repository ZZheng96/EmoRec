# 实验105：DEP01 窗口级CSP + pair自有阈值多数投票

## 结果

真实运行耗时278.31秒，使用40个窗口、8个物理trial、16个outer pair，未读取outer验证标签进行选择。

| 指标口径 | AUC | F1 |
|---|---:|---:|
| pooled probability（4 pair概率均值） | **1.000000** | 1.000000（仅作参考，固定0.5） |
| majority-vote（4个pair二值，sum>=2） | **1.000000** | **0.800000** |
| fixed-0.5（pooled probability） | **1.000000** | **1.000000** |
| pair mean（各pair自己的selected threshold） | **1.000000** | **0.687500** |

- 每个pair先用inner-only规则选出candidate、direction、threshold；outer valid每个窗口概率按trial五窗平均。
- AUC使用4个pair trial概率均值；F1使用每个pair自己的阈值二值化后多数投票`sum >= 2`。
- 平均selected threshold为0.453125；没有使用所有outer阈值均值，也没有事后改阈值。
- 由于本冻结口径要求以majority-vote F1作为最终F1，AUC/F1为1.000000/0.800000，未达到双0.95，不能宣称达标。
