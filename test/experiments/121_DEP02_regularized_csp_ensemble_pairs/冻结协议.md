# 实验121冻结协议

- 原始DEP02 40窗口、30通道、250Hz；五频带协方差沿用112加载与滤波实现。
- 物理标签严格为 `y::trial`，每trial五窗协方差先均值化，再作为一个样本拟合。
- outer固定4×4正负trial pairs（6 train/2 valid）；inner固定3×3（4 train/2 valid），outer验证标签不参与选择。
- 每训练折每频带收缩 C=(1-lambda)C+lambda*trace(C)/n*I，lambda={0,0.1,0.3,0.5,0.8}；FilterBank CSP n_components={2,4}；log-variance；特征块all/每band。
- 分类器仅LDA(lsqr, shrinkage=auto/0.1)及LogisticRegression(C=0.1/1/10)，共300候选，raw/reverse方向共600评分项。
- inner按AUC→F1@0.5→candidate序号→方向选择；outer仅用选定候选重新拟合并预测。主F1使用预冻结top-4配额，另报固定0.5。
- 单线程CPU：trial均值后矩阵规模小，GPU传输/启动不合算。禁止读取旧实验预测或选择结果。
