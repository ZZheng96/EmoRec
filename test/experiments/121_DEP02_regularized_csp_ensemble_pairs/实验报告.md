# 实验121：DEP02正则化FilterBank CSP集成严格配对

## 结果

- 主 pooled OOF：AUC **0.562500**，top-4 F1 **0.750000**。
- 固定阈值0.5：AUC **0.562500**，F1 **0.750000**。
- 16个outer pair均值：AUC **0.562500**，F1 **0.333333**。
- 候选300个，连同raw/reverse方向共600项；运行约125.81秒。

指标未达到0.95，不能宣称DEP02达标。结果是同被试8个开发trial的严格嵌套OOF证据，不等于独立测试集泛化。

## 协议执行

原始DEP02 40窗口（30通道、250Hz）沿用实验112加载与五频带协方差代码。每个物理trial的5个窗口协方差先逐频带均值化，形成8个trial样本，标签严格保存为`y::trial`。outer固定4×4正负pairs（6 train/2 valid），inner固定3×3（4 train/2 valid）；每个训练折独立拟合收缩、FilterBank CSP、StandardScaler和分类器，outer验证标签不参与选择。

收缩为`C=(1-lambda)C+lambda*trace(C)/n*I`，lambda为0、0.1、0.3、0.5、0.8；CSP每频带组件数2/4；log-variance特征块为all或单band；模型仅LDA(lsqr, shrinkage=auto/0.1)和LogisticRegression(C=0.1/1/10)。inner按AUC→F1@0.5→候选序号→方向选择。单线程CPU运行，原因是trial均值后的矩阵规模很小，GPU传输和启动成本不合算。

完整选择、冻结哈希、provenance、预测与指标均在本目录保存。
