# 实验185：DEP16固定阈值CSP严格验证

## 结果

- 主指标（8个trial pooled OOF）：AUC = **1.000000**，F1 = **0.857143**。
- 16个outer pair均值：AUC = 0.812500，F1 = 0.583333。
- 固定0.5常数基线：AUC = 0.500000，F1 = 0.666667。
- AUC达到0.95，但F1未达到0.95，故未达标。

## 协议与粒度

全部正负trial pair外层验证，inner仅使用外层训练trial选择模型和raw/reverse方向；固定阈值0.5，无quota、阈值搜索或外层标签参与选择。每个trial含5个窗口，4次outer预测先在trial内平均，再形成pooled trial概率。候选数120，单线程运行。

## 产物

`metrics.json`记录主指标、逐pair指标和协议参数；`predictions/pair_predictions.csv`为trial/pair级预测；当前脚本未保存`window_predictions.csv`，因此以上结果不能声称为40窗口级指标。
