# 实验208：无标签相似度软路由与多特征SVM分数融合

## 协议与防泄漏

严格subject-wise固定5折，排除HC43；每个被试只在一个验证折，物理trial的5窗口不跨折。DE、频谱、时域均按被试无标签zscore。训练fold拟合原型标准化/KMeans，验证被试仅用自身无标签DE均值/log标准差计算距离并以温度softmax路由；HC/DEP专家仅作已知健康元数据对照。软融合权重固定于训练协议，SVM多特征权重仅由外层训练被试内部OOF网格选择，验证标签未参与路由、温度或权重。057 plus_pe为冻结对照。
