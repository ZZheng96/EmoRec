# 实验072：固定链式图的频带拉普拉斯谱特征

冻结协议见 `test_protocol.txt`。每个10秒窗在4–8、8–13、13–30、30–45 Hz上构造30通道固定链式图，提取每带前4个非平凡归一化拉普拉斯特征值、谱熵和低频能量比，共24维；逐被试逐位置无标签z-score后追加070的720维PE，处理为744维，控制为同折070的720维PE。未访问公开数组。

耗时 **215.82秒**；60 fits；控制fixed002逐行复现070 `p_train8`；运行后测试 **6 passed**。
