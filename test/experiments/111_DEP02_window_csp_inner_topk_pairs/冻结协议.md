# 实验111冻结协议：DEP02严格嵌套inner-only top-k集成规模选择

- 新建独立目录 `111_DEP02_window_csp_inner_topk_pairs`，基于实验110实现，不覆盖旧实验。
- DEP02原始40窗口、8个物理trial，每trial 5窗；五频带FilterBank CSP，120个候选与raw/reverse共240个方向候选。
- outer为全部4×4正负trial pairs，每折30训练窗口/10验证窗口；inner为outer训练六个trial内3×3 pairs，每折20训练窗口/10验证窗口。
- 每个outer fold先对240个候选计算inner OOF trial聚合概率，按AUC降序、F1@0.5降序、candidate_index升序、direction_index升序冻结排序。
- K候选在运行前冻结为 **K={1,3,5,10,20}**，明确不包含240。对每个K取排序前缀，计算inner ensemble pooled AUC/F1@0.5；按AUC→F1→K较小选择selected_K。
- 选出的K个候选只在完整outer train窗口重训，并在outer valid窗口平均预测；不得用outer标签选择K、候选、方向或阈值。
- outer窗口预测先五窗均值为trial概率，再将每个trial的4个pair概率平均。最终AUC及F1均固定阈值0.5；不搜索阈值。
- 保存全部inner_scores、ranked_candidates、inner_k_scores、selected_K、预测、配置、哈希与来源信息。
