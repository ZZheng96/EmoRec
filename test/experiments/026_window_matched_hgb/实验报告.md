# 实验026：窗口匹配归一化与HGB

## 协议与泄漏审计
- 严格复用019的stable cache row ordinal % 5分为5批、8/40行逐被试总体zscore及002固定五折；输入为001的150维log_bandpower，排除HC43，2760行，未读取公开标签。
- 模型为StandardScaler + HistGradientBoostingClassifier：max_iter=200、learning_rate=.03、max_leaf_nodes=15、min_samples_leaf=20、l2_regularization=1、early_stopping=False；fold seed=2026+fold；数值线程固定1。无调参、无阈值选择，F1固定0.5。
- control_40_40逐行复现016 hgb_oof；matched_8_8训练/评估均8行；eval_only_40_8训练40行、评估8行。每行只预测一次，公开集每用户8行独立无标签归一化并校验提交格式。

## 解释边界
窗口按缓存行序取模，可能与实验条件/原trial排列相关；这不是随机窗口采样。被试内统计是无标签、传导式推断，行间相关，不能把2760行当独立样本。反复查看同一OOF进行协议选择会产生选择偏差，本实验不将比较结果解释为无偏的选模后性能或公开域保证。
