# 实验120：DEP02固定五窗mean低维PCA严格配对

日期：2026-11-03。先确认120目录不存在，再保存冻结协议/config，随后实现并运行；未修改119及更早实验，未提交git。

## 协议与实现

已阅读数据集说明。使用既有spectral/temporal/PE缓存，逐项核对subject/group/original_trial/y元数据；DEP02的8个物理trial合计40窗，各trial固定五窗mean，不选择聚合方法。保持119修复后的排序va与`y::trial`键，避免两类重复trial编号误合并或pair预测次序错位。

每次fit：StandardScaler → PCA(full SVD，whiten=False，维数1/2/3) → LogisticRegression(liblinear，C=0.1/1/10)。块all/spectral/temporal/PE，共36模型×raw/reverse=72评分项；没有其他候选。Scaler及PCA仅训练折拟合；内层4trial中心化后最多3维。外层4×4，共16个6训练/2验证pair；各外层内部3×3，共9个4训练/2验证pair。模型与方向仅依inner OOF AUC→F1@0.5→候选序号→方向序号选择。

每trial四次外层预测取均值；pooled主F1使用固定quota4稳定排序，另报固定0.5指标与pair均值。保存16×72=1152项inner评分、16项最终选择、32行pair预测、8行trial预测与window_rows元数据、输入及源码SHA256 provenance。

每次只有4–6行矩阵，GPU传输/启动成本大于小型full SVD与线性模型工作量，采用单线程CPU：threadpool_limits(1)，并设置OMP/MKL/OPENBLAS线程环境变量为1。没有新依赖、临时数据或模型文件；禁用字节码和pytest缓存。

