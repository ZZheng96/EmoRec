# 实验120：DEP02固定五窗均值低维PCA配对嵌套验证（运行前冻结）

- 仅使用DEP02训练数据及既有三份特征缓存。已阅读数据说明；每类4个50秒trial，每trial五个10秒窗，合计8trial/40窗。标签不是公开测试标签，不能解释为隐藏测试表现。
- 保留119的`y::trial`键、排序后的验证索引和窗口行对齐。外层4×4正负trial配对：6训练/2验证；内层3×3：4训练/2验证。每trial外层预测4次取均值。
- 聚合固定为逐trial五窗mean，禁止聚合方法选择。
- 每次fit管道严格为StandardScaler → PCA(svd_solver=full, whiten=False, n_components∈{1,2,3}) → LogisticRegression(C∈{0.1,1,10}, solver=liblinear, max_iter=3000, random_state=2026)。Scaler与PCA仅训练折拟合，验证折仅transform。内层4trial，中心化秩上限3。
- 特征块按all(720)、spectral(150)、temporal(450)、PE(120)排序，随后按PCA维数1/2/3、C=0.1/1/10排序，共36模型；每模型raw/reverse两个方向，共72评分项，不增加其他候选。
- 仅用inner OOF AUC、F1@0.5、候选索引、方向索引依次选择。外层标签不参与模型/方向选择。
- 保存全部16×72 inner评分、16个选定模型及方向、32条pair预测、8条trial均值预测与元数据、输入及源码SHA256 provenance；指标与119一致：pooled OOF AUC、quota4 F1、固定0.5 F1、pair-mean AUC/F1。quota4使用稳定排序选分数最高4trial，属于已知类别配额后处理，不以外层标签调阈值。
- 达标仅当pooled AUC和quota4 F1均≥0.95，未达标如实报告。该受试者反复方法探索不是独立确认集，不能据此宣称跨受试者泛化。
- 每次仅4–6行矩阵，GPU传输与启动开销不合算；使用单线程CPU及threadpool_limits(1)，不进行GPU加速。
