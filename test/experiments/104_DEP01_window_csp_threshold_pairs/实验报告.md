# 实验104：窗口级CSP + 严格inner-only阈值选择

| 指标口径 | AUC | F1 |
|---|---:|---:|
| 8个trial聚合OOF（inner选择阈值） | **1.000000** | **0.800000** |
| Pair指标均值（各折inner阈值） | **1.000000** | **0.687500** |
| 常数0.5 baseline | 0.500000 | 0.666667 |

- outer每折训练30窗口、验证10窗口；inner每折训练20窗口、验证10窗口。
- 候选120个；每个candidate/direction在inner OOF trial聚合概率上以F1最大选阈值，距离0.5最小破平；随后以AUC→F1→候选顺序选candidate/direction。
- 阈值候选固定为`np.linspace(0.05,0.95,19)`；外层验证标签未用于候选、方向或阈值选择，外层AUC使用概率，外层F1使用inner选择阈值。
- 16折、每个trial由4次pair预测覆盖；平均选定阈值为0.453125；运行耗时283.08秒。
- AUC达到0.95但F1未达到0.95，因此DEP01仍未达标，不能进入DEP02。该结果仅有8个物理trial，不能视为独立确认。
