# 实验044：独立10秒窗口wPLI相位连接

真实完成002固定5折（70人分折后排除HC43）及032式2027..2031五次重复（69人重新分折）。2760训练窗口、80公开窗口。仅复用001原始频谱特征缓存，不读取历史OOF概率；所有控制逐折重训。

## 定义与协议

10个预先固定左右通道对 × 5频带 = 50维。各独立10秒窗口先四阶Butterworth带通+sosfiltfilt默认边缘填充，再Hilbert解析信号。wPLI = |mean(Im(zL conj(zR)))| / mean(|Im(zL conj(zR))|)，分母零时为0；时间点是期望样本，未作去偏修正或边缘裁切。这是时间域解析信号wPLI估计，不是Welch近似、不是相位角PLV，也不是跨试次谱wPLI。有限窗口/滤波边缘会产生估计偏差。

特征提取完全不接收标签、行序、trial id或邻窗；训练/验证/公开使用相同函数，wPLI无被试跨窗归一化。每折StandardScaler+HGB只fit训练被试，验证仅transform/predict。对照按要求保留150维subject-zscore无标签转导归一化（使用同被试其他窗口），这不属于严格单窗口处理，和wPLI路径明确区分。HGB参数与032一致，seed=2026+fold，阈值0.5。不调参，不用公开标签。每重复独立OOF；公开仅一次全训练拟合保存预测，不报告公开指标。
