# 实验036：无标签同批次窗口一致性特征

复用001 spectral 150维、009 temporal 450维缓存与002固定5个被试级折，排除HC43。每行先按被试无标签z-score；新增特征为原始150维加同一数据集被试按行顺序连续块的均值、标准差、当前行减块均值（训练每5行，公开每2行），共600维。公开8个窗口没有被伪装为5段trial，也没有用训练trial_id映射公开块；该特征仅是跨数据集结构假设下的无标签块统计，不等同真实trial标签。

一致性主方法相对spectral_control的AUC差为+0.045154。若低于对照，不将其解释为有效创新；块大小假设、行顺序依赖及公开块不是真实trial是主要限制。
