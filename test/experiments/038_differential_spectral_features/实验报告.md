# 实验038：跨通道差分频谱方向

## 目的与严格边界

001 的 spectral cache 只有150维带功率，无法恢复原始通道时序，因此本实验没有把缓存通道功率相减冒充波形差分。差分特征直接复用 `src/emo_rec/data.py` 的原始EEG加载和10秒窗口逻辑，在每个窗口内计算固定同源左右电极对的逐频带 log-bandpower 差；它是行序不敏感的跨通道频谱差，不是波形差分。

训练每被试40个10秒窗口，公开每用户8个10秒窗口；特征逐窗口计算，未使用相邻行、original_trial_id、y、health_group或公开标签。每被试独立无标签z-score，排除HC43。固定002外层五折、HGB参数和0.5阈值。比较150维spectral_control、60维differential_spectral，以及每折重训的固定0.5/0.5融合。

## 复核设计

另用032的seed=2027..2031独立生成被试级分层五折，对control和differential_spectral分别完整运行OOF。重复折只作为稳定性复核，未拼接成独立样本，也未进行重复折显著性检验。公开数据只保存预测，不报告公开性能。

## 实测结果

固定折真实结果（排除HC43）：spectral_control AUC/F1/BAcc=0.782416/0.718671/0.717754，subject macro AUC=0.769710，HC/DEP AUC=0.833932/0.674856；differential_spectral=0.532133/0.515217/0.515217，subject macro AUC=0.532826，HC/DEP AUC=0.537473/0.523440；固定0.5/0.5融合=0.756288/0.703289/0.702536，subject macro AUC=0.745688，HC/DEP AUC=0.807435/0.655424。032重复折五组均值：spectral_control AUC/F1/BAcc=0.781203/0.712115/0.710580，differential_spectral=0.535286/0.526040/0.526449；逐重复、逐折指标见`metrics.json`与OOF文件。差分方向显著低于控制组，因此停止该方向，不宣称泛化提升。不得手工补写不存在的结果。

## 文件与命令

- `cache/differential_features.npz`：原始窗口逐窗差分频谱缓存及元数据。
- `predictions/`：固定折和重复折OOF、公开预测。
- 特征运行：`.venv\\Scripts\\python.exe -B test/experiments/038_differential_spectral_features/run_experiment.py --rebuild-features`
- 专项测试：`.venv\\Scripts\\python.exe -B -m pytest -q -p no:cacheprovider test/experiments/038_differential_spectral_features/test_protocol.py`

若差分方向低于spectral_control，则结论限制为本协议下未见提升并停止该方向，不宣称公开泛化；若提高，也仅作为固定协议的探索性证据。
