# 实验053：分层误差审计（纯诊断）

不训练新模型、不调参、不使用公开集指标。输入为052 `spectral_temporal_hgb_control` 六个分割（fixed002 + repeat2027..2031）的OOF，以及046 `spectral_control`（仅频谱150维）六个分割的OOF作对照；特征审计使用001频谱150维 + 009时序450维，逐被试无标签z-score（与052一致）。脚本：`run_audit.py`，日志：`run_output.txt`，全部数值：`metrics.json`，明细表：`tables/`。

**数据结构更正**：`original_trial_id` 是每个标签内部的1..4，而不是1..8；每个(被试, trial_id)有10行（5中性+5积极）。物理trial = (被试, 标签, trial_id)，脚本中记为 `trial_key = original_trial_id + 4*y`（1–4中性，5–8积极）。已断言 69×8 个trial、每个5行、标签恒定，六个OOF文件行序一致，各fold之间没有被试泄漏。

## 1. 窗口 vs trial vs 被试层级（spectral+temporal，6分割均值）

| 层级 | 总体 | HC | DEP |
|---|---:|---:|---:|
| 窗口池化AUC | 0.789 | 0.840 | 0.681 |
| trial均值池化AUC | 0.859 | 0.904 | 0.755 |
| 被试内窗口AUC宏均值 | 0.774 | 0.828 | 0.679 |
| 被试内trial AUC宏均值 | 0.836 | – | – |

把5个窗口平均成trial后AUC提升约0.07，说明有相当一部分误差是trial内的窗口噪声。不过trial层面仍有约0.14的损失，HC与DEP的差距（0.904 vs 0.755）也没有缩小，所以剩余误差集中在trial/被试层级。仅频谱模型的规律相同（窗口0.781 → trial 0.860）。注意：trial聚合要用到trial标识，052协议把它列为禁用预测量，这里只作诊断用。

## 2. 被试AUC稳定性
- 被试窗口AUC在6个分割之间的相关：Pearson均值0.968（最小0.958），Spearman 0.970；trial级Spearman 0.930。
- 被试AUC跨分割的平均标准差为0.025，被试间标准差为0.153，类ICC比值为0.968。
- 仅频谱模型与频谱+时序模型的被试AUC相关：Spearman 0.980。
- 6个分割全部反转（AUC<0.5）的被试只有1个（DEP17）；≥4/6反转的有3个（全部是DEP）；6分割均值<0.6的有13个（HC 3、DEP 10）。HC被试AUC中位数0.862，DEP中位数0.669。

**结论**：被试难度几乎完全由数据决定，与折划分和模型（频谱或频谱+时序）都无关。

## 3. 被试偏移是否是瓶颈 → 否定
池化AUC 0.789 **已经高于**被试内宏均值0.774。无标签的被试内中心化只到0.791（+0.001），被试内logit z-score降到0.780，被试内rank降到0.774。被试间的概率偏移不是损失来源；反过来，被试间的尺度差异在池化时还略有帮助。

## 4. 极性：Oracle上界（使用验证标签，不是可用模型）
把反转被试翻转为1-p后AUC只到0.794（+0.005，平均翻转3人），DEP从0.681升到0.696。"整体反转的被试"只能解释很小一部分损失。

无标签代理与被试AUC的Spearman相关：trial均值极差 ρ=0.75，trial间方差占比 0.72，概率标准差 0.69，双峰系数 0.67（全体样本均 p<1e-9）；在DEP内部明显减弱（0.33–0.45）。均值概率和|均值-0.5|都无关。这些代理能看出"哪些被试模型有把握"，但看不出极性；用来识别反转被试的AUC只有0.64–0.80（n=3，不可靠）。

## 5. 特征效应方向一致性（被试z-score后600维，被试内Cohen's d）
| 指标（窗口级d，top30按mean\|d\|） | HC | DEP | 置换零分布（均值 / 95%分位） |
|---|---:|---:|---:|
| 符号一致率 | 0.933 | 0.689 | 0.538 / 0.584 |
| mean\|d\| | 1.27 | 0.61 | 0.54 / 0.60 |
| 按群体方向的带符号d | 1.19 | 0.36 | – |

- 600维整体mean|d|：HC 0.505，DEP 0.339；HC与DEP的平均d向量相关0.67（trial级为0.55）。
- 对齐度（被试d向量与留一群体均值d的相关）：HC 0.58，DEP 0.22（Mann-Whitney p=3e-5）。对齐为负的被试有10个（HC 3、DEP 7）；trial级d下为7个，全部是DEP。
- 对齐度与被试OOF AUC的Spearman相关：全体 ρ=0.84，HC内0.73，DEP内0.89（trial级d：0.86 / 0.79 / 0.89）。改用HC模板计算结果相同。
- trial级d的结论一致：HC符号一致率0.94，DEP 0.70。

**解读**：DEP的情绪效应方向在0.69左右，高于零分布但远不如HC一致；效应量只有HC的一半左右，top-30的|d|已经落在置换零分布的95%分位附近。所以DEP的主要问题是**效应弱 + 个体特异**，完整反转只占少数。对齐度与AUC的高相关部分在意料之中（模型学到的就是群体共有方向），属于描述性关系；但它说明误差来自"被试是否共享群体方向"，与分类器的形式无关。注意top-30特征的选择由HC主导（44 vs 25人），对DEP不利。

## 6. trial / 刺激异质性 → 不支持
8个trial_key的正确率（被试内中心化后判定，6分割平均概率）在0.75–0.81之间，异质性卡方 p=0.995（标签内分别为 p=0.90 / 0.97）。HC和DEP分组也不显著（p=0.18 / 0.38），DEP中trial_key 7的正确率较低（0.52），但n=25。trial_id是否对应同一刺激**无法确认**，因此该检验对刺激特异性标签噪声的效力有限。

误差在被试层面过度离散：每个被试错分trial数的方差/二项方差 = 1.52，全对的被试有19个（二项期望9.4），错3–4个的有24个（期望16.2）。误差按被试聚集，不是在trial上随机分布。

## 7. 被试簇bootstrap（fixed002，2000次，seed 2053）
- 池化AUC 0.789，95%CI [0.751, 0.825]
- HC−DEP AUC差 0.165，95%CI [0.090, 0.237]，差值≤0的比例为0

## 假设判定
| 假设 | 判定 |
|---|---|
| trial内窗口噪声 | **部分支持**：trial平均+0.07，但HC/DEP差距不变 |
| 被试概率偏移/校准是瓶颈 | **否定**：中心化+0.001，rank变差 |
| 反转响应者（极性）是瓶颈 | **基本否定**：稳定反转只有1–3人，oracle翻转+0.005 |
| 弱/个体特异响应者（尤其DEP） | **支持**：DEP的\|d\|约为HC的一半，符号一致率0.69 vs 0.93，对齐度–AUC ρ=0.84 |
| 刺激特异的trial标签噪声 | **不支持**（检验效力有限） |
| 被试难度是数据固有属性 | **强支持**：跨分割ICC 0.97，跨模型ρ 0.98 |

**关于约0.79上限的理论**：窗口级AUC约0.79由两部分构成。(a) trial内窗口噪声，约0.07，可以通过trial聚合回收，但涉及协议问题。(b) 被试层面的响应强度和方向异质性：约1/5的被试（13/69的6分割均值AUC<0.6，其中10个DEP；DEP整体对齐度只有0.22）与群体共享的情绪EEG方向弱相关或不相关，在被试间不变的特征空间里，对这些被试无法超越机会水平太多。这部分误差无法通过偏移校准、极性翻转、重加权（052）或更换特征/分类器来消除。它在不同分割和模型之间高度稳定，HC−DEP差距的95%CI下界为0.09。
