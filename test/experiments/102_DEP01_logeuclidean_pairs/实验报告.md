# 实验102：DEP01 log-Euclidean trial-level 嵌套配对 OOF

## 方法与防泄漏

依据数据说明与101实现，40个10秒窗口先按8个物理trial各5窗平均五频带协方差。每次inner/outer拟合独立计算训练trial各band算术均值参考，特征为正则化SPD矩阵对数相对参考的上三角，StandardScaler仅拟合训练样本。64个模型/epsilon/C/频带候选与raw/reverse方向均只在inner 3×3配对OOF中选择。outer 4×4配对仅预测，阈值固定0.5，每trial平均4次outer预测。完整候选分数及划分见input_metadata/selections.json。

101冻结协议与config残留100标识、固定raw及特征后聚合文字；102使用独立正确协议，未覆盖101代码或配置，仅按要求更新其报告测试状态。

## 真实结果

| 指标口径 | AUC | F1 |
|---|---:|---:|
| 8个trial聚合OOF（主指标） | **0.562500** | **0.333333** |
| 16个pair指标均值 | 0.562500 | 0.416667 |
| 常数0.5 baseline | 0.500000 | 0.666667 |

- trial数8，窗口数40，每trial prediction_count=4，pair预测行数32。
- 64模型候选，含方向共128选择项；16个outer折各9个inner折。
- 运行耗时43.50秒；Python 3.11.9；CPU单线程。使用项目既有NumPy/SciPy/sklearn，小矩阵实验未新增GPU依赖。
- 实际运行命令：`py -3.11 test/experiments/102_DEP01_logeuclidean_pairs/run_experiment.py`。
- 实际验证命令：`py -3.11 -m pytest test/experiments/101_DEP01_filterbank_csp_direction_pairs/test_101.py test/experiments/102_DEP01_logeuclidean_pairs/test_102.py -q`。
- 测试结果：**5 passed in 3.02s**，其中101为2 passed，102为3 passed。102测试覆盖聚合OOF/指标重算、outer划分与inner候选选择、参考和标准化训练隔离、单样本预测不受验证同伴影响、5窗聚合及输入/代码/配置/协议哈希。

## 结论与边界

当前AUC=0.562500、F1=0.333333，未同时达到0.95，DEP01未达标。相较101的AUC=0.875000、F1=0.857143明显下降，F1也低于常数0.5基线。未根据本次outer结果调向、调阈值或重新筛选候选。

该结果仅8个物理trial，估计方差大；方法探索已参考101结果，因此无折内泄漏不等于独立测试集评估。SVC sigmoid分数未校准，不能解释为可靠的概率估计。没有据此宣称泛化达标，也未推进DEP02。
