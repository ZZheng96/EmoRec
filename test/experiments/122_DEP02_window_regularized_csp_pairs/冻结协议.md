# 实验122冻结协议：窗口级收缩 FilterBank CSP 严格配对

1. 使用 DEP02 原始40窗口；五频带为1–4、4–8、8–13、13–30、30–45Hz，250Hz采样，四阶Butterworth。每个物理trial固定5个窗口，标签和排序使用 `y::trial`。
2. outer固定4×4正负物理trial pair，每折30训练窗口/10验证窗口；inner固定训练trial内3×3 pair，每折20/10窗口。窗口不跨折，outer验证标签不参与选择。
3. 每个训练折、每个窗口协方差先按 C=(1-lambda)C+lambda*trace(C)/30*I 收缩，lambda={0,0.1,0.3,0.5}；随后每频带拟合FilterBank CSP，components={2,4}，提取log-variance空间特征。StandardScaler和分类器只在当前训练窗口拟合。
4. 候选为4 lambda×2 components×5 blocks(all/band_1..band_4)×2 models(LinearSVC/LogisticRegression)×4 C=320；raw/reverse方向共640评分项。inner先平均每trial五窗口概率，再以全部inner trial概率按AUC、固定0.5 F1、候选序号、raw优先选择。
5. outer重新在训练窗口拟合选定候选；验证预测先五窗口平均为trial概率，再四个pair平均得到8个OOF trial概率。固定报告top-4 quota和固定0.5，两者均不回选。
6. 记录完整config、哈希冻结、provenance、选择、pair/pooled预测、metrics和测试；单线程CPU，不读取旧实验结果。
