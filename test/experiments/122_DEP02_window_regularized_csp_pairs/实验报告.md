# 实验122：DEP02窗口级收缩 FilterBank CSP 严格配对

## 真实结果

- 主 pooled OOF（top-4 quota）：AUC **0.500000**，F1 **0.500000**。
- 固定阈值0.5：AUC **0.500000**，F1 **0.500000**。
- 16个 outer pair 均值：AUC **0.312500**，F1 **0.395833**。
- 候选320个，raw/reverse共640项；单线程 Python 3.11 运行约256.62秒。

指标未达到0.95，不能宣称DEP02达标。结果是同被试8个开发trial的严格嵌套OOF证据，不等于独立测试集泛化。

## 协议执行

沿用实验110的DEP02原始40窗口和五频带协方差。每个训练折内每个窗口协方差独立执行收缩 `C=(1-lambda)C+lambda*trace(C)/30*I`，lambda={0,0.1,0.3,0.5}，再拟合每频带FilterBank CSP（components={2,4}）并提取log-variance特征。特征块为all及band_1至band_4，分类器仅LinearSVC/LogisticRegression，C={0.01,0.1,1,10}。

outer固定4×4物理正负trial pairs（30/10窗口），inner固定3×3（20/10窗口）；inner先按trial平均五窗口概率，再选择候选和raw/reverse方向。outer验证标签不参与选择；StandardScaler、收缩、CSP和分类器均只在训练窗口拟合。输出同时固定报告top-4 quota和0.5阈值，未挑选最好指标。
