# 实验123冻结协议：窗口级Riemannian MDM严格配对

1. 使用DEP02原始40窗口；五频带为1–4、4–8、8–13、13–30、30–45Hz，250Hz采样、四阶Butterworth；每个物理trial固定5窗口，标签和排序使用`y::trial`。
2. outer固定4×4正负物理trial pair，每折30训练窗口/10验证窗口；inner固定训练trial内3×3 pair，每折20/10窗口；验证trial先排序，outer验证标签不参与选择。
3. 每训练折每窗口协方差执行C=(1-lambda)C+lambda*trace(C)/30*I，lambda={0,0.1,0.3,0.5}，随后trace归一化。每band分别以训练类样本的仿射不变Karcher均值为prototype，固定20次、步长0.5、训练类算术均值初始化。
4. 候选为4 lambda×6 blocks(all/band_1..band_5)×2 distances(riemann/euclidean_logm)=48；raw/reverse共96项。Riemann分数为d(C,prototype0)-d(C,prototype1)，转sigmoid；inner按trial均值概率AUC、F1、候选序号、方向选择。
5. outer重新仅用训练窗口拟合收缩和prototype；窗口概率先按trial均值，再按4个pair均值形成8个OOF trial概率。报告pooled主AUC、quota4主F1、fixed0.5和pair均值。
6. 保存config、冻结协议、完整选择、pair/pooled predictions、metrics、freeze/provenance及测试；单线程CPU。
