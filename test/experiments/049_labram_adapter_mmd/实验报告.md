# 实验049：LaBraM冻结底层 + Adapter/MMD

日期：2026-11-01。严格复用004的官方LaBraM缓存（输入30×10×200、200维embedding、官方权重已在004核验）和001的150维log-bandpower；训练69名被试、2760个10秒窗口，排除HC43，严格002五折。每外层折只用训练被试拟合分类器/Adapter，验证及公开仅transform；公开标签未使用。

## 条件

- `spectral_hgb_control`：150维频谱subject-zscore + 固定HGB，同脚本逐折重训。
- `frozen_labram_linear`：LaBraM embedding冻结，仅线性分类头。
- `adapter`：冻结embedding输入，只训练32维瓶颈Adapter和线性头。
- `adapter_mmd`：在Adapter训练损失中加入固定权重0.05的训练折内被试域均值MMD，仅使用训练折无标签域批次，不使用验证样本。

## 结果

固定seed=2026：控制 AUC/F1/BAcc/subject宏AUC/HC-DEP AUC = **0.781800/0.717986/0.715942/0.768297/0.835843-0.670208**；冻结线性 **0.650859/0.612100/0.605072/0.671558/0.684561-0.588256**；Adapter **0.642857/0.616762/0.612319/0.660000/0.668267-0.597272**；Adapter-MMD **0.648520/0.607220/0.605797/0.667029/0.675743-0.598412**。

seeds 2027..2031各自独立OOF，均值：控制 AUC **0.780125**、DEP AUC **0.674124**；冻结线性 **0.644820**、DEP **0.587849**；Adapter **0.634884**、DEP **0.593657**；Adapter-MMD **0.639766**、DEP **0.594465**。三种LaBraM轻量条件均低于频谱HGB，尤其DEP，按协议停止，不调参。

## 复现与限制

先运行专项测试：`5 passed in 5.15s`。真实运行命令为 `python test/experiments/049_labram_adapter_mmd/run_experiment.py --repeats`，输出见run_output.txt，完整指标见metrics.json，逐次OOF和公开预测见predictions。049复用了004已完成的真实权重/输入兼容性核验；没有重新加载权重，避免重复GPU长耗时。此前005端到端微调曾发生CUDA挂起，且结果低于频谱控制，本实验因此只验证冻结表征上的轻量头/Adapter。公开预测仅保存格式，不报告公开性能。
