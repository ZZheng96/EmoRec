# 实验030：ROI频谱汇聚与trial内稳健偏差

复用001的150维频谱缓存、009的450维temporal缓存和002固定五折，排除HC43；所有特征构建不使用标签，并按被试分别zscore。ROI通道严格采用项目`CHANNEL_NAMES`常量，四个请求ROI覆盖30通道且无重叠。注意：四个ROI×5频带×3统计量实际为60维，任务文字中的75维与给定四ROI划分不一致，本实验未虚构第五ROI。稳健偏差为每个被试每个原trial连续5行相对trial中位数的mean absolute deviation和median-centered signed deviation，各300维并逐窗重复。
