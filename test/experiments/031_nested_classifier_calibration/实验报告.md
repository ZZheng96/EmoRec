# 实验031：嵌套分类器容量选择与Platt校准

复用001 spectral 150维与009 temporal 450维，排除HC43，复用002固定5个外层被试折；两分支均按被试无标签zscore，单线程。每个外层训练集内使用seed=2026+fold的3折被试级StratifiedKFold产生inner OOF，仅以AUC、F1、接近control leaf=15的顺序选择leaf 7/15/31；另以LR(C=1)作低容量参照。Platt sigmoid为每个分支单独在inner OOF概率logit上拟合，外层验证只用于最终报告。融合权重固定0.5，主F1阈值固定0.5；inner选择阈值仅记录。
