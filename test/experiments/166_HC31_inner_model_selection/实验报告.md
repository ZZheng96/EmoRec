# 实验166：HC31 inner-only模型选择

## 目标

在不修改实验161及旧实验的前提下，针对HC31寻找固定阈值下AUC/F1双达标方法。输入沿用实验091的720维训练缓存，严格执行外层留一物理trial、内层留一trial候选选择。

## 冻结协议

- 仅使用001 spectral、009 temporal、057 permutation entropy训练缓存；不读取公开数组。
- HC31共40窗、8个物理trial，每trial 5窗；沿用091的逐被试40窗无标签z-score。
- 每个外层折验证1个完整trial（5窗），训练其余35窗；外层标签不参与模型/方向选择。
- 外层训练集内使用7个trial inner CV，固定比较720维 StandardScaler+LinearSVC、LogisticRegression、HistGradientBoosting，并分别比较raw/reverse分数方向。
- 选择顺序固定为inner pooled AUC → inner F1 → 候选固定index；外层重训后输出5窗概率均值。
- 所有最终判定固定阈值0.5；没有事后阈值、quota或外层标签搜索。
