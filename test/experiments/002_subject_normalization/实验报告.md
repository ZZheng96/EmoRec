# 实验 002：被试内无标签归一化与 HC43 敏感性

> 日期：2026-10-31
> 状态：已完成，已复核
> 主指标：被试独立折外预测的全局 Trial-level ROC AUC

## 1. 研究问题与假设

实验 001 表明，绝对对数带功率存在显著被试间偏移：最佳模型全局 OOF AUC 仅为 0.670246，但被试宏平均 AUC 为 0.740250，且不同被试的预测概率尺度差异很大。本实验固定特征、分类器和被试折，检验以下问题：

1. 完整排除近零幅值异常被试 HC43 后重训，结果是否明显变化。
2. 每名被试的无标签特征中心化能否减小跨被试偏移。
3. 在中心化基础上进行被试内标准化，能否进一步改善全局 AUC、被试内排序和 HC/DEP 分组稳定性。

假设：若主要瓶颈是被试间位置和尺度偏移，被试内归一化应显著提高全局 OOF AUC，并缩小全局 AUC 与被试宏平均 AUC 之间的差距；若情绪信号本身不足，则被试宏平均 AUC 的提升会有限。

## 2. 文献依据

- 跨被试 EEG 情绪识别综述区分了全被试与单被试归一化，并将利用无标签目标数据的方法归入传导式方法；因此本实验不与完全目标无关的域泛化协议混报。[cite:1]
- Apicella 等指出，EEG 域适应实验中的部分收益可能主要来自预先进行的归一化，均值平移本身即可视为一种简单域适应。本实验因此先单独检验中心化和 z-score，而不直接叠加复杂域适应模型。[cite:2]
- 上述研究来自不同数据与任务，只支持实验设计，不预设本数据集必然获得相同幅度的提升。

## 3. 数据、特征与模型

- 直接复用实验 001 的 `cache/features.npz`，不重新提取特征，不引入外部数据。
- 使用 150 维 `log_bandpower`：30 通道×5 频段的 10 秒 Welch 对数功率。
- 分类器固定为 `StandardScaler + LogisticRegression(C=1, penalty=L2, max_iter=2000, solver=lbfgs)`。
- 沿用实验 001 的 5 折被试级分层划分，随机种子 2026。折先在全部 70 名被试上生成；排除 HC43 的条件仅删除该被试，其余被试折分配不变。
- 每折的 StandardScaler 仍只在训练折拟合。验证被试不会参与分类器或全训练折统计量的拟合。
- 阈值固定为 0.5；不在公开测试集上调节任何参数。

## 4. 传导式被试内归一化协议

对每名被试的每个特征独立计算：

- `center`：`x' = x - mean(x_subject)`。
- `zscore`：`x' = (x - mean(x_subject)) / std(x_subject)`。
- 标准差不大于 `1e-12` 时除数置为 1，避免近零方差导致数值发散。
- 训练/验证阶段，每名被试使用其全部 40 个缓存片段的无标签特征计算统计量。由于同一被试只属于一个外层折，不会跨被试混入验证信息，也不使用验证标签。
- 公开测试阶段，每名用户使用其 8 个 trial 的无标签特征独立计算统计量。

该协议假定推理时可获得目标被试的一个 batch，属于**传导式归一化**。它不等同于逐 trial、完全目标无关的推理；公开集与私有集均需采用相同 batch 口径。

## 5. 对照条件

| 条件 | 被试内归一化 | 训练与评估是否完整排除 HC43 |
|---|---|---|
| `raw_exclude_hc43` | 无 | 是 |
| `subject_center_all` | center | 否 |
| `subject_zscore_all` | zscore | 否 |
| `subject_center_exclude_hc43` | center | 是 |
| `subject_zscore_exclude_hc43` | zscore | 是 |

排除条件从外层训练、验证评估和最终全量训练中均删除 HC43，不是仅删除其 OOF 预测。公开测试始终输出全部 10 名用户的 80 个 trial。

### 6.2 与实验 001 的关系

- 实验 001 的全部 70 被试原始特征基线：全局 OOF AUC=0.670246、binary F1=0.632866、被试宏 AUC=0.740250。
- 在全部 70 被试上，中心化使全局 AUC 增加 0.087771，z-score 使其增加 0.092707。
- 在相同的 69 被试集合上，z-score 相对原始特征完整重训使全局 AUC 增加 0.100252、被试宏 AUC 增加 0.036232。
- `raw_exclude_hc43` 与实验 001 的评估人群不同且经过完整重训，不能把其分数直接当作“只删除 HC43 OOF 行”的结果。

## 7. 分析

### 7.1 主要收益来自跨被试对齐

- 最佳条件全局 AUC=0.764749，被试宏 AUC=0.758406，两者已接近；实验 001 则被试宏 AUC 明显高于全局 AUC。
- 被试平均预测概率的标准差由实验 001 的 0.186525 降至 0.015168；被试概率均值范围由约 0–0.937293 收敛到 0.440968–0.538123。
- 在相同 69 名被试上，z-score 的全局 AUC 增幅为 0.100252，而被试宏 AUC 增幅为 0.036232。说明大部分全局增益来自跨被试概率/特征尺度对齐，被试内情绪排序也有较小改善。
- 69 名被试中，50 名被试内 AUC 提升、3 名不变、16 名下降，中位提升 0.020000；并非所有被试都受益。

### 7.2 中心化与标准化的差异

- 在排除 HC43 的相同人群上，z-score 相比 center 的全局 AUC 仅再提高 0.004669，被试宏 AUC 提高 0.015725。
- 中心化已经获得主要收益；逐特征方差缩放是较小但一致的附加改进。当前固定折结果不足以证明该小差异具有统计显著性。

### 7.3 HC43 敏感性

- 原始特征下，排除 HC43 并未解决低分问题，说明 HC43 不是唯一瓶颈。
- z-score 下，保留或排除 HC43 的全局 AUC 仅相差约 0.0018，但两者评估人群不同，不能解释为严格的配对增益。
- HC43 在 `subject_zscore_all` 中仍只有被试内 AUC=0.5，所有样本被预测为积极类。归一化不能从近零信号中恢复情绪信息，因此后续默认采用完整排除 HC43 的条件，同时保留含 HC43 结果用于审计。

### 7.4 DEP 仍是主要瓶颈

- 最佳条件相对 `raw_exclude_hc43`：HC pooled AUC 提高 0.109846，DEP pooled AUC 提高 0.073400，两组均改善，没有以 DEP 退化换取整体提升。
- 但最佳 DEP pooled AUC 仍仅为 0.681340，明显低于 HC 的 0.808432；DEP 被试宏 AUC 仅提高 0.019500，HC 则提高 0.045739。
- 被试间尺度偏移得到明显缓解，但被试内、尤其 DEP 组的情绪可分信息仍不足。当前结果距离 AUC/F1 均为 0.95 的研发目标仍有明显差距。

## 8. 局限与下一步

1. 本轮在相同 OOF 折上比较了 5 个条件，最佳分数存在模型选择乐观偏差，不能当作完全无偏的泛化估计；后续确定特征方向后需用重复被试折或 LOSO 复核。
2. z-score 使用目标被试整批无标签数据，公开测试每名用户仅 8 个 trial；私有集若 batch 构成不同，统计量稳定性可能变化。
3. 本轮仅改变归一化与 HC43 处理，没有增加新的情绪信息。下一步固定 `subject_zscore_exclude_hc43` 作为新基线，优先检验相对频段功率/频谱形状特征能否改善被试内、尤其 DEP 组排序；若简单频谱表示仍不足，再进入 Euclidean Alignment、空间协方差或 EEGNet 实验。
4. 当前不进行低质量线上提交，不自动消耗提交次数。
